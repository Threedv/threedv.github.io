# Research evidence assets

These are Gyeongsu Cho's coauthored research artifacts, reproduced with source attribution for his portfolio. Videos are derived from real project demonstrations, encoded as H264 MP4 for browser playback; no still images were turned into simulated research demos.

- `dogrecon-teaser.png`: https://vision3d-lab.github.io/dogrecon/img/teaser.png
- `dogrecon-animation.mp4`: https://vision3d-lab.github.io/dogrecon/img/app1.mp4
- `dogrecon-paper.pdf`: https://link.springer.com/content/pdf/10.1007/s11263-025-02485-5.pdf (IJCV 2025; see source licensing)
- `wildani4d-teaser.jpg`: https://vision3d-lab.github.io/wildani4d/assets/teaser.jpg
- `wildani4d-demo.mp4`: https://vision3d-lab.github.io/wildani4d/assets/demo1.mp4 (comparisons on generated videos)
- `wildani4d-paper.pdf`: https://vision3d-lab.github.io/wildani4d/assets/wildani4d_paper.pdf
- `anigauss-paper-figure2.png`: unaltered rendering of Figure 2, page 4, in the author-provided public workshop manuscript below
- `anigauss-demo.mp4`: https://vision3d-lab.github.io/anigauss/assets/demo1_anigauss.mov
- `anigauss-workshop-paper.pdf`: https://drive.google.com/file/d/17wsFGZl_MrP_hQqFXrHYEvTtc4dZdLsw/view
- `slabins-paper.pdf`: https://openaccess.thecvf.com/content/ICCV2023/papers/Lee_SlaBins_Fisheye_Depth_Estimation_using_Slanted_Bins_on_Road_Environments_ICCV_2023_paper.pdf
- `pose-diverse-vton-paper.pdf`: https://openaccess.thecvf.com/content/WACV2026/papers/Han_Pose-Diverse_Multi-View_Virtual_Try-on_from_a_Single_Frontal_Image_via_WACV_2026_paper.pdf

Paper-reported numbers displayed on the site:
- DogRecon, PDF page 8 / Table 2: CLIP-Similarity 0.8006, internet-sourced image-to-3D evaluation.
- WildAni4D, PDF page 6 / Table 1: MPJPE 91.29 and Shape Consistency 0.0703, synthetic test set. No units inferred.
- SlaBins, PDF page 6 / Table 1: RMSE 1.040 and Abs Rel 0.022, SynWoodScape.
- AniGauss: qualitative-only evaluation; no numerical performance claim.

Public access is not a blanket reuse license. Preserve original credit and consult each paper's licensing for uses outside this author's research portfolio.
